# Subprocessors

A subprocessor is a company that processes personal data for us, so that we can operate the
Service. This page lists all of them. The [Privacy Policy](/legal/privacy/) tells what data we
process and for how long.

## Current subprocessors

| Company | What it does for us | Data | Where |
| --- | --- | --- | --- |
| Cloudflare, Inc. | Hosts the website, the API and the dashboard (Workers), the database (D1), custom emoji storage (R2), the AI models (Workers AI), anonymous search statistics (Workers Analytics Engine, kept three months), our own short logs without search text, keys or IP addresses (Workers Logs, kept up to 7 days), the edge cache and the rate limits | All data in the Privacy Policy, including IP addresses while requests are in transit | Global network. Company in the United States. |
| Clerk, Inc. | Sign-in to the dashboard: accounts, sessions, sign-in emails and abuse protection (with Cloudflare Turnstile) | Name, email addresses, a password hash if you set a password, linked social accounts, and the IP address and browser of each sign-in | United States |

The AI models that we use, for example EmbeddingGemma or bge-m3 for search and a Gemma model for
photo descriptions, run on Cloudflare's servers. The companies that made the models (Google and
BAAI) do not receive any data.

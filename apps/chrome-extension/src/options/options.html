Picker

Sets the emoji labels and the picker text (English or Turkish). “Same as the browser” follows Chrome’s languages. Search understands this language, English and Chrome’s preferred languages, on this device.

Skin tone

For people and hands, such as 👍 and 👋.

Search by meaning Optional

With the Emojisense API, a description such as “we shipped it” finds 🚀. Off by default: when it is on, the text you type in the picker goes to the API address below. Nothing else leaves this device.

On-device results stay. Matches by meaning are added to them.

Only a publishable key (pk_…) belongs in a browser. Add this extension to the key’s allowed origins.

Canvas editors

Some online word processors draw text on a canvas, not in a text field. There the picker copies the emoji and you paste it with ⌘V.

Also try to put the emoji straight into canvas documents.

Settings and recently used emoji stay on this device.
